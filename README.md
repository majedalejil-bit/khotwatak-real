# 👟 خطوتك ربح - عداد الخطوات الذكي

> تطبيق عداد خطوات **حقيقي 100%** يعمل في الخلفية بدون محاكاة

## ✨ الميزات

- ✅ **تتبع حقيقي** - يستخدم Health API الأصلي من نظام التشغيل
- ✅ **يعمل في الخلفية** - يتتبع الخطوات حتى مع إغلاق التطبيق
- ✅ **يعمل في الجيب** - لا يحتاج شاشة مفتوحة
- ✅ **مظهر احترافي** - واجهة عربية جميلة مع Dark/Light Mode
- ✅ **حفظ محلي** - جميع البيانات في جهازك فقط
- ✅ **إحصائيات دقيقة** - مسافة مقطوعة، سعرات حرارية، وقت نشاط

## 📱 التثبيت السريع

### للمستخدمين (تحميل مباشر)

1. انتظر الرابط المباشر للـ APK من المطور
2. افتح الرابط على هاتفك الأندرويد
3. انقر **تنزيل**
4. انتقل إلى **الإعدادات** → **الأمان**
5. فعّل **التطبيقات من مصادر غير معروفة**
6. ثبّت التطبيق من **المحتويات المحملة**

### للمطورين (البناء المحلي)

```bash
# تثبيت المكتبات
npm install

# البناء للويب
npm run build

# لعرض محلي
npm run dev

# إضافة Android
npx cap add android

# نسخ الملفات
npx cap copy

# فتح في Android Studio
npx cap open android
```

انظر [BUILD_AND_DEPLOY.md](BUILD_AND_DEPLOY.md) للتفاصيل الكاملة.

## 🎯 كيفية العمل

### على Android:

1. التطبيق يطلب إذن `ACTIVITY_RECOGNITION` (تتبع النشاط)
2. يتصل بـ Health API الأصلي للهاتف
3. يقرأ عدد الخطوات من مستشعرات الهاتف الحقيقية
4. يحدّث الواجهة كل 5 ثوان
5. يحفظ البيانات محلياً في `localStorage`

### التطبيق سيستمر في التتبع:
- ✅ عند إغلاق الشاشة
- ✅ عند إغلاق التطبيق (إذا كان Android يسمح)
- ✅ حتى مع تشغيل تطبيقات أخرى
- ✅ طالما الهاتف قيد التشغيل

## 📊 الإحصائيات

يعرض التطبيق:
- **الخطوات اليومية** - العدد الفعلي
- **النسبة المئوية** - من الهدف 10,000 خطوة
- **النقاط** - 1 نقطة لكل 10 خطوات
- **المسافة** - بناءً على طول الخطوة (0.76 متر)
- **السعرات** - حساب تقريبي (0.04 سعرة/خطوة)
- **الوقت** - دقائق النشاط المقدّرة

## 🎨 المظهر

- **الوضع الفاتح** 🌙 - أبيض بأخضر
- **الوضع الداكن** ☀️ - رمادي بأخضر
- **ملء الشاشة** - تطبيق حقيقي بدون متصفح
- **عربي كامل** - واجهة RTL احترافية

## ❓ الأسئلة الشائعة

**س: هل يعمل بدون إنترنت؟**
> نعم، التطبيق يعمل بدون إنترنت بالكامل. جميع البيانات محفوظة محلياً.

**س: هل البيانات آمنة؟**
> نعم، جميع البيانات تبقى على جهازك فقط. لا توجد خوادم أو نقل بيانات.

**س: هل يستنزف البطارية؟**
> لا، التطبيق يستخدم Health API الأصلي الذي مُحسّن للبطارية. المراجعة كل 5 ثوان فقط.

**س: كيف أشارك البيانات؟**
> البيانات محفوظة محلياً فقط حالياً. يمكنك نسخ الأرقام يدوياً أو إضافة خاصية التصدير لاحقاً.

**س: هل يعمل على iOS؟**
> التطبيق مُصمَّم لـ Android. يمكن إضافة دعم iOS لاحقاً باستخدام CoreMotion.
