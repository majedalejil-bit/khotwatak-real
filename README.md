# خطوتك ربح v2

عداد خطوات حقيقي لأندرويد (APK) — بيعدّ **والشاشة مطفأة** والتطبيق مسكّر.

## كيف بيشتغل
- **حسّاس الخطوات الأصلي** بالهاتف (Step Counter): بيعدّ لحاله طول الوقت، وبطارية شبه صفر.
- **خدمة بالخلفية** مع إشعار ثابت «👟 1,234 خطوة اليوم» — هي اللي بتمنع أندرويد يوقف العدّاد.
- بعد إعادة تشغيل الهاتف بيرجع يشتغل لحاله.
- إذا الهاتف ما فيه حسّاس خطوات: بيعدّ بحسّاس الحركة (احتياطي).

## الملفات (كل ميزة بملف لحالها)
- `www/` واجهة التطبيق
  - `kw-js-01-core.js` الأساس · `kw-js-02-native.js` الربط مع العدّاد الأصلي
  - `kw-js-03-home.js` الرئيسية · `kw-js-04-stats.js` الإحصائيات · `kw-js-05-badges.js` الشارات
  - `kw-js-06-setup.js` خطوات التشغيل · `kw-js-07-settings.js` الإعدادات · `kw-js-08-start.js` البداية
  - `kw-css-0X-*.css` تصميم كل ميزة
- `native/java/` كود أندرويد الأصلي: `StepService` (الخدمة) · `StepStore` (التخزين) · `StepCounterPlugin` (الجسر) · `BootReceiver`
- `scripts/patch-android.mjs` بيضيف الكود الأصلي لمشروع أندرويد
- `.github/workflows/build-apk.yml` بيبني الـ APK على GitHub تلقائياً
- `keystore/khotwatak.jks` مفتاح التوقيع (لا تحذفه: التحديثات بتنزل فوق القديم بفضله)
