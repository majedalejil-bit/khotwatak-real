🎯 الخطوات التفصيلية:
─────────────────────────────────────────────────────────────────────────────

1. تثبيت المتطلبات:
   ✓ Node.js 16+ (https://nodejs.org)
   ✓ Android Studio (https://developer.android.com/studio)
   ✓ Java JDK 11+

2. تثبيت المشروع:
   npm install

3. بناء التطبيق:
   npm run build

4. إضافة منصة Android:
   npx cap add android

5. فتح في Android Studio:
   npx cap open android

6. بناء APK في Android Studio:
   Build → Build Bundle(s) / APK(s) → Build APK(s)

7. نشر على الإنترنت:
   - رفع APK على Netlify (مجاني)
   - الحصول على رابط تحميل مباشر
